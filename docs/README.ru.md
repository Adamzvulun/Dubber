# «Дубляж видео» — инструкция

Программа делает из видео с YouTube (на английском или любом другом языке, даже если в видео говорят на
нескольких языках) **видео с озвучкой на русском** — или на одном из 12 языков, — а также **субтитры** и **текст**.
Всё работает на вашем компьютере.

## Установка (один раз)
1. Скачайте папку программы на компьютер (её подготовит Адам).
2. Откройте папку `scripts` и дважды щёлкните **`install_windows.bat`**.
3. Если окно попросит запустить установку ещё раз — закройте его и снова дважды щёлкните `install_windows.bat`.
4. В конце на рабочем столе появится ярлык **«Дубляж видео»**.

## Обновление (когда Адам выпустил новую версию)
1. Закройте чёрное окно «Дубляж», если оно открыто.
2. Скачайте новую версию (Адам пришлёт ссылку: GitHub → ветка `main` → **Code → Download ZIP**) и распакуйте её
   **в ту же папку**, заменив файлы. Видео, настройки и ключ сохранятся.
3. Дважды щёлкните `scripts\install_windows.bat`, потом запускайте программу ярлыком на рабочем столе.
4. Внизу страницы написан номер версии (например, «Дубляж 0.3.0») — по нему видно, что обновление прошло.
Если при запуске окно пишет «Дубляж уже запущен», значит, открыто ещё одно чёрное окно программы — закройте его и
запустите снова.

## Как пользоваться
1. Дважды щёлкните ярлык **«Дубляж видео»**. Откроется окно программы (не закрывайте его) и сайт в браузере.
2. Скопируйте адрес видео на YouTube и вставьте его в поле на главной странице.
3. **Язык озвучки** — по умолчанию русский (можно выбрать один из 12 языков). Голос — **мужской** или **женский**.
4. Переключатель **«Оригинальный звук фоном»**: включён — оригинальная речь и музыка тихо звучат под озвучкой;
   выключен — слышна только озвучка.
5. Нажмите **«Озвучить»**. Карточка покажет, на каком этапе работа. Видео на 10 минут обычно готово за 5–10 минут.
   Рядом с таймером видно, примерно сколько осталось (оценка уточняется по ходу работы).
   Страницу можно закрыть — работа продолжится. Передумали — нажмите **«Отменить»**; если потом начать заново,
   уже сделанная часть работы не пропадёт.
6. Нажмите **«Смотреть»**. Справа от видео — текст: перевод и оригинал. Текущая фраза
   подсвечивается, а щелчок по любой строке перематывает видео на это место.
7. Кнопки под видео сохраняют файлы: видео, субтитры, текст, «Оригинал + перевод».
8. Вверху справа переключатель **RU / EN** — язык самого сайта, и значок шестерёнки — **«Настройки»** перевода.

Все видео собраны в разделе **«Библиотека»**. Там же их можно удалить.

## Полезно знать
- В видео две звуковые дорожки: озвучка и оригинал.
  В плеере VLC переключение: меню **Аудио → Аудиодорожка**.
- Нужен интернет: для скачивания, перевода и озвучки.
- Перевод и голос делает компьютер, поэтому возможны неточности. Если важная фраза звучит странно —
  посмотрите файл «Текст с оригиналом».
- Обычно переводит Google (бесплатно). Если он временно недоступен, программа сама переключится на резервный
  переводчик, который работает прямо на компьютере (в первый раз он скачивается — около 1,4 ГБ). Он переводит чуть
  хуже; на странице видео тогда будет пометка. Позже можно озвучить видео заново — переведёт Google.

## Перевод с Claude (по желанию, платно)
Claude — ИИ-переводчик компании Anthropic. Он видит всё видео целиком, переводит по смыслу и подбирает длину фраз
под время говорящего, поэтому озвучка звучит естественнее. Стоит примерно **$0,09 за 10 минут речи** (модель
Opus 5.5; модели Sonnet и Haiku дешевле).
1. На сайте [console.anthropic.com](https://console.anthropic.com) создайте учётную запись, пополните счёт
   (**Billing**) и задайте месячный лимит расходов (**Limits**), например $5 — больше этой суммы списано не будет.
2. В разделе **API Keys** нажмите **Create Key** и скопируйте ключ (он начинается с `sk-ant-`).
3. В программе откройте **«Настройки»** (шестерёнка вверху), вставьте ключ и нажмите **«Проверить и сохранить»**.
   Ключ хранится только на этом компьютере.
4. Готово: под полем ссылки на главной странице будет написано «Перевод: Claude». На странице видео видно, кто
   переводил и сколько это стоило. Если на счёте кончатся деньги, программа сама переведёт через Google и
   напишет об этом.
5. **Глоссарий** (там же, в настройках): слова, которые нужно переводить именно так, по одному в строке —
   «термин = перевод». Подходит для любой темы.
Уже озвученное видео после добавления ключа можно озвучить заново — его переведёт Claude.

## Если что-то не работает
| Сообщение | Что делать |
|---|---|
| «Не удалось скачать видео» | Проверьте ссылку и интернет. Запустите `install_windows.bat` ещё раз — он обновит программу. |
| «Сервис Google Translate недоступен» | Подождите и попробуйте позже. Без Google можно переводить только с английского на русский. |
| «Ключ не подошёл» (в настройках) | Скопируйте ключ из консоли Anthropic ещё раз целиком (он начинается с `sk-ant-`). |
| «Claude не перевёл (на счёте нет средств)» | Пополните счёт на console.anthropic.com (Billing) и озвучьте видео заново. |
| «Нет связи с интернет-сервисом» | Проверьте интернет и нажмите кнопку ещё раз — программа продолжит с того же места. |
| «Дубляж уже запущен» при запуске | Закройте другое чёрное окно программы и запустите её снова. |
| После обновления не видно нового (например, шестерёнки «Настройки») | Посмотрите номер версии внизу страницы. Если он старый — закройте все чёрные окна «Дубляж», запустите `install_windows.bat` из новой папки и откройте программу ярлыком. |
| Страница не открывается | Убедитесь, что чёрное окно программы открыто; откройте в браузере адрес `http://127.0.0.1:7860`. |
| «Не удалось скачать видео» повторяется, хотя интернет есть | YouTube мог попросить подтверждение «я не робот». Напишите Адаму: он настроит файл cookies. |
| Другое | Сфотографируйте сообщение и отправьте Адаму. |
