# «Дубляж видео» — инструкция

Программа делает из видео с YouTube, TikTok, Instagram или Facebook или из видеофайла с компьютера (на английском или любом другом языке, даже если в
видео говорят на нескольких языках) **видео с озвучкой на русском** — или на одном из 12 языков, — а также
**субтитры** и **текст**. Всё работает на вашем компьютере.

## Установка (один раз)
1. Скачайте программу: GitHub → **Code → Download ZIP** (или Адам пришлёт архив) и распакуйте её в удобную папку,
   например «Документы».
2. Дважды щёлкните файл **«Start Dubber»** в этой папке. Если Windows спросит, можно ли запустить файл, — нажмите
   «Запустить» (или «Подробнее → Выполнить в любом случае»).
3. В первый раз программа сама установит всё нужное (Python, ffmpeg и свои компоненты) — это 10–15 минут, окно
   пишет, что происходит. Затем на рабочем столе появится ярлык **«Дубляж видео»** со значком программы, и сайт
   откроется в браузере.
4. Дальше запускайте программу этим ярлыком. Если ярлык пропал — снова дважды щёлкните «Start Dubber».

## Обновление
**С версии 0.5.0 программа обновляется сама.** При каждом запуске она проверяет, не вышла ли новая версия, и, если
вышла, скачивает её (обычно несколько секунд, иногда несколько минут — окно напишет «Обновляю…»). Если программа уже
открыта, а новая версия вышла, вверху страницы появится надпись «Вышла новая версия программы» и кнопка
**«Установить обновление»** — страница перезагрузится сама. После обновления на странице один раз появится
«Что нового» — список изменений. Видео, настройки и ключ сохраняются. Без интернета программа просто
запускается как обычно. (Отключить: строка `DUBBER_AUTO_UPDATE=0` в файле `.env`.)

Если у вас версия старше 0.5.0 (номер внизу страницы), обновите её вручную ещё один, последний раз:
1. Закройте чёрное окно «Дубляж», если оно открыто.
2. Скачайте новую версию (Адам пришлёт ссылку: GitHub → ветка `main` → **Code → Download ZIP**) и распакуйте её
   **в ту же папку**, заменив файлы. Видео, настройки и ключ сохранятся.
3. Дважды щёлкните «Start Dubber» в папке программы, потом запускайте её ярлыком на рабочем столе.
   Установка может идти несколько минут; если строки в окне долго (больше 15 минут) не меняются — закройте окно и
   отправьте Адаму файл `install.log` из папки программы.
4. Внизу страницы написан номер версии (например, «Дубляж 0.3.1») — по нему видно, что обновление прошло.
   Если страница выглядит странно (огромные значки, надписи вроде `nav.settings`) — браузер показывает старые
   сохранённые файлы: нажмите **Ctrl+Shift+Delete**, отметьте «Изображения и файлы в кэше» и очистите, затем
   обновите страницу. Это нужно не больше одного раза (с версии 0.3.1 обновления видны сразу).
Если при запуске окно пишет «Дубляж уже запущен», значит, открыто ещё одно чёрное окно программы — закройте его и
запустите снова.

## Как пользоваться
1. Дважды щёлкните ярлык **«Дубляж видео»**. Откроется окно программы (не закрывайте его) и сайт в браузере.
2. Скопируйте адрес видео на YouTube, TikTok, Instagram или Facebook и вставьте его в поле на главной странице. Можно вставить **несколько ссылок**
   — каждую с новой строки (Shift+Enter), они озвучатся по очереди. Ссылка на **плейлист** озвучивает все его видео;
   если ссылка ведёт на видео внутри плейлиста, программа спросит: только это видео или весь плейлист.
   Видео **с компьютера**: нажмите «выберите видеофайл на компьютере» или перетащите файл на поле.
   Instagram (а иногда Facebook и TikTok) отдаёт видео только после входа в аккаунт — см. «Вход на сайты» ниже.
3. **Язык озвучки** — по умолчанию русский (можно выбрать один из 12 языков). Голос — **мужской** или **женский**.
4. Переключатель **«Оригинальный звук фоном»**: включён — оригинальная речь и музыка тихо звучат под озвучкой;
   выключен — слышна только озвучка.
   Переключатель **«Убрать голос диктора»** (по умолчанию выключен): музыка и звуки видео остаются, а голос
   оригинального диктора убирается — слышна только озвучка поверх музыки. Это дольше: примерно +5 минут на каждые
   10 минут видео (в первый раз программа ещё скачает нужную модель, около 170 МБ).
   **Голос «Оригинал»** — озвучка голосами самих говорящих (программа копирует голос каждого человека в видео).
   Только для компьютеров с видеокартой NVIDIA с памятью от 6 ГБ; устанавливается один раз в «Настройках» →
   «Голос оригинала» → «Установить» (около 6 ГБ, 10–30 минут). Для иврита не работает — будет мужской голос.
5. Нажмите **«Озвучить»**. Карточка покажет, на каком этапе работа. Видео на 10 минут обычно готово за 5–10 минут.
   Рядом с таймером видно, примерно сколько осталось (оценка уточняется по ходу работы).
   Страницу можно закрыть — работа продолжится. Передумали — нажмите **«Отменить»**; если потом начать заново,
   уже сделанная часть работы не пропадёт.
6. Нажмите **«Смотреть»**. Справа от видео — текст: перевод и оригинал. Текущая фраза
   подсвечивается, а щелчок по любой строке перематывает видео на это место. Под плеером — **«Субтитры на видео»**:
   два переключателя, язык озвучки и **«Оригинал»** (можно один, оба или ни одного).
7. Кнопки под видео сохраняют файлы: видео, субтитры, текст, «Оригинал + перевод».
8. Вверху справа переключатель **RU / EN** — язык самого сайта, и значок шестерёнки — **«Настройки»**: перевод,
   «Вход на сайты», «Голос оригинала» и «Место на диске».

Все видео собраны в разделе **«Библиотека»** (вверху — поиск по названию). У каждого видео одна карточка; значки
языков на ней (RU, EN…) показывают, на какие языки оно озвучено. Карточка открывает последнюю озвучку, а под видео
есть ссылки «Другие озвучки этого видео». Повторная озвучка с теми же настройками заменяет прежнюю. Кнопка
«Удалить» стирает только открытую озвучку.

**Место на диске** (Настройки): программа хранит скачанные оригиналы в кэше, чтобы повторная озвучка (например, на
другой язык) шла быстрее. Если места мало — нажмите «Очистить кэш» у видео или «Очистить весь кэш». Готовые видео в
библиотеке при этом остаются.

## Полезно знать
- В видео две звуковые дорожки: озвучка и оригинал.
  В плеере VLC переключение: меню **Аудио → Аудиодорожка**.
- Нужен интернет: для скачивания, перевода и озвучки.
- Перевод и голос делает компьютер, поэтому возможны неточности. Если важная фраза звучит странно —
  посмотрите файл «Текст с оригиналом».
- Обычно переводит Google (бесплатно). Если он временно недоступен, программа сама переключится на резервный
  переводчик, который работает прямо на компьютере (в первый раз он скачивается — около 1,4 ГБ). Он переводит чуть
  хуже; на странице видео тогда будет пометка. Позже можно озвучить видео заново — переведёт Google.

## Вход на сайты (Instagram, Facebook, TikTok)
Видео, открытые для всех, скачиваются сразу. Для видео, которые сайт показывает только после входа в аккаунт:
1. Установите в Chrome или Edge расширение **«Get cookies.txt LOCALLY»** (ссылка — в «Настройки» → «Вход на сайты»).
   Именно «LOCALLY»: другие расширения с похожим названием небезопасны.
2. Откройте сайт (instagram.com, facebook.com или tiktok.com) и войдите в аккаунт.
3. Значок расширений (пазл) → «Get cookies.txt LOCALLY» → **«Export»** — файл сохранится в «Загрузки».
4. «Настройки» → «Вход на сайты» → **«Добавить файл входа»** → выберите файл. Для другого сайта повторите 2–4.

Файл входа — как пароль, никому его не отправляйте. Программа хранит только вход на эти четыре сайта и только на
этом компьютере (файл `cookies.txt` в папке программы). Вышли из аккаунта в браузере — добавьте вход заново.

## Перевод с Claude (по желанию, платно)
Claude — ИИ-переводчик компании Anthropic. Он видит всё видео целиком, переводит по смыслу и подбирает длину фраз
под время говорящего, поэтому озвучка звучит естественнее. Стоит примерно **$0,09 за 10 минут речи** (модель
Opus 5.5; модели Sonnet и Haiku дешевле).
1. На сайте [console.anthropic.com](https://console.anthropic.com) создайте учётную запись, пополните счёт
   (**Billing**) и задайте месячный лимит расходов (**Limits**), например $5 — больше этой суммы списано не будет.
2. В разделе **API Keys** нажмите **Create Key** и скопируйте ключ (он начинается с `sk-ant-`).
3. В программе откройте **«Настройки»** (шестерёнка вверху), вставьте ключ и нажмите **«Проверить и сохранить»**.
   Ключ хранится только на этом компьютере.
4. Готово: под полем ссылки на главной странице будет написано «Перевод: Claude». На странице видео видно, кто
   переводил и сколько это стоило. Если на счёте кончатся деньги, программа сама переведёт через Google и
   напишет об этом.
5. **Глоссарий** (там же, в настройках): слова, которые нужно переводить именно так, по одному в строке —
   «термин = перевод». Подходит для любой темы.
Уже озвученное видео после добавления ключа можно озвучить заново — его переведёт Claude.

## Если что-то не работает
| Сообщение | Что делать |
|---|---|
| «Не удалось скачать видео» | Проверьте ссылку и интернет. Закройте чёрное окно и запустите программу снова — раз в несколько дней она обновляет загрузчик видео. |
| «Сервис Google Translate недоступен» | Подождите и попробуйте позже. Без Google можно переводить только с английского на русский. |
| «Ключ не подошёл» (в настройках) | Скопируйте ключ из консоли Anthropic ещё раз целиком (он начинается с `sk-ant-`). |
| «Claude не перевёл (на счёте нет средств)» | Пополните счёт на console.anthropic.com (Billing) и озвучьте видео заново. |
| «Нет связи с интернет-сервисом» | Проверьте интернет и нажмите кнопку ещё раз — программа продолжит с того же места. |
| «Дубляж уже запущен» при запуске | Закройте другое чёрное окно программы и запустите её снова. |
| После обновления страница «сломана» (огромная шестерёнка, надпись `nav.settings`) | **Ctrl+Shift+Delete** → «Изображения и файлы в кэше» → очистить, затем обновить страницу. |
| После обновления не видно нового (например, шестерёнки «Настройки») | Посмотрите номер версии внизу страницы. Если он старый — закройте все чёрные окна «Дубляж», дважды щёлкните «Start Dubber» в новой папке и откройте программу ярлыком. |
| Страница не открывается | Убедитесь, что чёрное окно программы открыто; откройте в браузере адрес `http://127.0.0.1:7860`. |
| «Не удалось скачать видео» повторяется, хотя интернет есть | YouTube мог попросить подтверждение «я не робот». Напишите Адаму: он настроит файл cookies. |
| Другое | Сфотографируйте сообщение и отправьте Адаму. |
